# Probing Geometry of Next Token Prediction Using Cumulant Expansion of the Softmax Entropy
We investigate how token representations evolve within neural networks, particularly Large Language Models, by applying cumulant expansion to the probability distributions generated by the softmax function.

## Repository Overview

This repository contains tools for computing layer-wise cumulants of language model logits and comparing structured and shuffled token sequences. The main analysis code lives in `cumulant_analyzer.py`. Experiments and helper plotting utilities can be found in the `experiments` directory.

### Key Features
- Load pretrained causal language models along with a tuned lens.
- Compute cumulants up to eighth order for each transformer layer.
- Compare entropy and cumulant statistics between structured text and shuffled baselines.
- Generate plots illustrating how prediction geometry changes across depth.

### Running an Analysis
Install requirements such as `torch`, `transformers`, and `tuned_lens`. Then create an instance of `CumulantAnalyzer` and run:

```python
from cumulant_analyzer import CumulantAnalyzer
analyzer = CumulantAnalyzer("gpt2")
stats = analyzer.compute_stats("Example text here.")
```

The resulting dictionary contains normalized cumulants, entropies, and KL divergences.

### Experiments
Jupyter notebooks in `experiments` reproduce the figures shown in the `experiments/plots` folder. These notebooks demonstrate usage of the analyzer on different models.
